This update ports applicable product fixes into the public Polaris implementation. It preserves the public repository's intentional SQLite architecture, typed native chat storage, hydration boundaries, and existing installation data. It is not a replacement with another product's storage layer.

## Intentional boundaries

- Public native SQLite startup, typed chat persistence, data authority, import transactions, and legacy migration boundaries remain public-owned. Other implementations' KV journals, boot repair scans, and storage-specific batching are not copied over them.
- The public Chatbox converter produces a structured replacement package and explicitly tells the user to back up current data before restoring it. It does not acquire another implementation's additive-import startup ownership repair. A structured-package import continues to follow the public import UI and its existing replacement/commit rules.
- Generic native file and WebDAV download transport may supply ranged sources. The public full-backup importer still consumes a Blob, so its adapter materializes that input and releases the native handle. This is not a claim of streaming full-database restoration.
- Public provider networking remains direct-first with deployer-configured relay fallback. Official service origins, operator consoles, production update manifests, signing identities, release records, uncommitted work, and personal data are not synchronized.
- Existing public behavior is retained where a later patch addresses a path that does not exist here or is already handled differently, including typed SQLite reads and the selection-specific message editor scroll contract.
